# A4 audit (after pass 1b and the E2 follow-up)

Scope: the full corpus with the pass-1b coverage additions (974 components, up from 881), fresh dumps from all four language-server runs, and the E2 follow-up rules.

## Pass 1b: corpus coverage

New code was added for grammar scopes the corpus did not reach. Coverage is scopes produced ÷ scopes reachable in each grammar, counting only scopes a theme can colour.

| Grammar | Before | After |

Unchanged: ARM 82%, CMake 94%, devicetree 93%, diff 77%, git-commit 82%, INI 85%, JSON 87%, Kconfig 67%, linker 72%, Makefile 96%, YAML 98%. Most of the remaining missing scopes are `meta.*` and punctuation variants that carry no colour of their own (`meta.tail.*`, `punctuation.separator.scope-resolution.*`) or need malformed code.

## E2 follow-up (rules found by 1b)

- C++: qualified namespace names (`outer::inner`, `namespace a = b::c`, `using namespace a::b`) → namespace; owner of an out-of-line definition (`Led2::get`, `Led2::operator==`) → user type.
- C/C++: exponent sign (`1e-3`, `0x1p+4`) → unit, as in Rust; C++ digit separator (`1'000`) stays number.
- Rust: macro metavariables `$addr` take the parameter colour as a whole (P8); fragment specifiers (`expr`, `ty`) → keyword.
- Python: triple-quoted raw strings → string. Shell: `for` loop variable → config variable.
- **Rosin's log grammar**: ESP-IDF `V (…)` verbose lines were matched together with `D` debug lines; they now get their own `log.verbose` scope (the comment colour), as the expectation always said. [`../edits/E2-grammar.diff`](../edits/E2-grammar.diff)
- Six corpus expectations were corrected (out-of-line method name is a method; a file-scope function pointer is a global; `ty` is a fragment specifier; four duplicate component names renamed and aligned with the originals).

## Confirmation in the real editor
